# 发动机及后处理试验数据分析系统 v7 · 自动出图版

运行环境：Windows 64 位，已安装 MWORKS.Syslab 2026b。解压完整文件夹后双击 `SyslabCANAnalyzer.exe`，不要单独移动 exe。

## 操作

1. 选择含 ASC 或物理量 CSV 的数据文件夹，点击“扫描数据”，选中一个文件。
2. ASC 使用附带的两份 DBC，也可以在界面中更换。选择输出文件夹。
3. 点击“解析并导出 CSV”只导出物理量；点击“生成全部图像”则先解析，再根据有效字段调用 Syslab 自动绘图。也可单独点击某类分析。
4. 从预览下拉框选择实际生成的图，点击“图窗编辑”调整坐标、标题、字体和图例，或滚轮缩放查看。编辑区域只列出实际存在的子图。

设置按钮可改标题、Logo 和备注。左侧操作区可滚动；运行信息可滚轮滚动，并可拖动上方分隔线调整高度。

## 自动出图规则

- 以 Word 要求的 22 个字段为范围。字段有至少一个有限有效值，才绘制对应时域子图；单个有效样本用点显示。
- 缺列、全空、全 NaN 或全部无效码的字段省略，不再显示“无有效数据”占位图。
- 某类全部字段都无效时，不生成这类图片；界面显示已跳过，运行信息说明原因。这属于正常完成。
- 数值为 0 是有效数据，会保留和绘图；恒定值也保留。不能把零值当作缺失。
- 子图数量和画布高度随实际字段自动调整；标题、坐标及默认字体沿用宋体和 Times New Roman。
- 频谱还要求最长连续有效转速段至少 32 点，并有有效正采样间隔；工作点还要求同通道、同源地址、同时间戳的转速与实际扭矩成对出现。只有某一个字段时不会生成不适用的组合分析图。
- “生成全部图像”检查所有类别；单独点击按钮只执行该类别。导入新记录或改变通道/源地址后，已知图像结果会更新，避免显示上一次数据的旧图。跳过某类时会清除该类旧图片，CSV 和用户格式设置保留。
- CSV 始终保留全部来源，绘图筛选只影响图像。多个有效车速来源分别绘制、标注来源，不拼接成同一条信号。

## 字段与分析类别

| 类别 | 覆盖字段 |
| --- | --- |
| 时域分析 | 发动机转速、燃油消耗率、实际扭矩百分比、车速 |
| 温度分析 | 冷却液温度、机油温度、燃油温度 1、大气温度 |
| 压力与液位 | 机油压力、大气压力、燃油输出压力、机油油位、冷却液液位 |
| 电压分析 | 发动机输入电压、点火开关电压、充电系统输出电压（信息表中的电源电压采样） |
| 油门与可用扭矩 | 油门踏板开度、实际最大可利用发动机扭矩百分比 |
| 累计计量 | 累积工作时间、总转数、行程燃油、本次记录的累计燃油积分 |
| 频谱分析 | 转速的全段及低频幅值谱，满足连续采样条件时生成 |
| 工作点分析 | 转速—实际扭矩百分比，满足成对条件时生成 |
| 分布分析 | 转速、实际扭矩百分比分布，有哪项绘哪项 |
| 传感器 ADC | SensorCAN 中 AI11、AI16、AI18 原始计数，属于表格以外的附加项 |

因此，即使只收到油门、压力、电压或累计计数中的某一种有效字段，点击“生成全部图像”也能生成对应类别；不会强制要求转速等主字段齐全。

## 本次记录的结果

本次约 20 秒 ASC：13 项有效报文物理量、1 项记录内燃油积分、3 路有效 ADC 原始计数。自动生成 9 类图：时域、频谱、工作点、分布、温度、压力与液位、ADC、油门与可用扭矩、累计计量。

电压类无有效数据，不生成电压图片。温度图有 3 个子图，压力与液位图有 2 个子图，累计计量图有 3 个子图。未取得有效值的 8 项仍可在 CSV/质量报告核查，详细原因见字段说明。

## 输出与解释

输出包含物理量 CSV、`signal_mapping.csv`、逐信号追溯长表、质量报告及实际生成的 PNG。各 PNG 旁的 `.panels.toml` 记录实际子图及跳过原因，供图窗编辑自动识别。`analysis_context.json` 标记本次数据和绘图筛选条件。

CSV 空单元格表示本条报文未更新该信号，NaN 表示无效；均不补零。累计燃油为同一通道/来源的有效燃油率在本次记录内进行梯形积分，断点和长间隙不跨越，不是 ECU 生命周期油耗。ADC 缺少工程标定，不直接当作拉力或电压。扭矩为百分比，缺少参考扭矩时不换算 Nm 或 kW。

依然使用 Syslab 2026b 的 Julia、TyMath、TyPlot 分析绘图，未使用 MATLAB。TXT 入口仅支持 ASC 内容格式；不直接读取 BLF。DBC 有数千个信号，本版仍按 Word 目标表筛选，不表示全量解析 DBC 信号。兼容旧版六通道 CSV 的原有四类图。
