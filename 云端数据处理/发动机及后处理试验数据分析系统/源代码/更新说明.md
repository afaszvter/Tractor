# 2026-10-31 更新

- 基于 1021 试验系统修改，原有功能继续保留。
- 实测旧版 exe 无法读取本次 CAN 表格 TXT；新增自动识别与解析，不要求用户先转换为 ASC。
- 默认传感器 DBC 更新为 adc_in1_force_10kN.dbc，实际系数 0.002 kN/计数。
- 新增传感器力时域图及有效非零力样本分布图；原有传感器 ADC 分析保留，未重复新增原有整车分析按钮。
- 新图纳入生成全部图像、图像预览、图窗编辑和格式重绘；没有有效数据时跳过。
- 来源行号、输入/DBC 的 SHA256、通道、原始 CAN ID、原始字节、无效原因仍可追溯。

- 传感器力默认聚焦主要受力区间，使该区间约占横轴的 80%；只调整显示范围，保留全部小非零数值。
- 图窗编辑新增“完整时域”和“自动聚焦”，可切换完整时间轴与默认聚焦视图。
- 拉力分布仅排除严格等于 0 的样本，不剔除小非零力值。
