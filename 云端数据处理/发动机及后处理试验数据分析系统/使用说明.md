# 发动机及后处理试验数据分析系统

版本：2026-10-31，TXT 与传感器力版。Windows 64 位；绘图需要已安装并授权 MWORKS.Syslab 2026b。

## 使用

1. 解压整个程序文件夹，双击 SyslabCANAnalyzer.exe；不要单独移动 exe 或 _internal。
2. 选择数据文件夹，点击“扫描数据”，选中记录。
3. 默认加载随包的 j1939.dbc 与 adc_in1_force_10kN.dbc，可自行选择其他 DBC。
4. 选择输出目录，点击“解析并导出 CSV”或直接点击分析按钮。
5. “传感器力分析”生成 IN1 力时域图；“拉力分布”统计有效非零力样本。原有时域、频谱、工作点、分布、温度、压力与液位、电压、油门和累计量分析继续保留。
6. “生成全部图像”仅生成有有效数据的图，无效或缺失字段跳过，并在运行信息中说明。
7. 在预览下拉框选择图种，点击“图窗编辑”，可缩放、拖动、修改标题、坐标范围、字体和图例，并由 Syslab 重新绘图。

## 输入格式

- CAN 表格 TXT：支持本次 2026_10_31_121046_ID0001.txt 的逗号分隔表，表头含时间标识、CAN通道、ID号、帧类型、帧格式、CAN类型、长度、数据；兼容 GB18030 和 UTF-8。
- Vector 经典 CAN ASC / ASC 格式 TXT。
- 本程序导出的物理量 CSV；兼容旧六通道 CSV。
- 该版不直接导入 BLF；TXT 的支持取决于内容格式，不是任意文本文件。

## IN1 标定

标准帧 0x301，8 字节，D0–D1 大端，原始值乘以 0.002 kN。原始值 2500=5 kN、5000=10 kN。原 DBC 文件的标题和注释仍写旧的 0.01 / 50 kN，程序依据实际 SG_ 定义，不依据注释；原 DBC 声明的物理范围 0–50 kN 保留，未自行改为 0–10。

只解析已定义的一路 IN1；0x302、D2–D7 不推断为第二路或第三路力。旧 SensorCAN.dbc 也随包保留，需要原 ADC 分析时可以切换至该 DBC，ADC 不会被冒充为 kN。

## 数据与图形

通道和源地址分开保留；自动绘图按单个字段选择有效来源，实际来源写入运行信息。当前 TXT 的力来源为 CAN1 标准帧，整车来源为 CAN2 / 0x00，不需要修改原始通道。CSV 导出不前向填充；空白为本帧未更新，NaN 为字段无效，合法 0 保留。每个输入文件生成独立目录，包含物理量 CSV、逐样本追溯表、信号映射、质量报告和适用 PNG。TXT 的系统时钟文字保留在原文件，分析使用“时间标识”的相对秒数，不自行校时。

图形仍通过 MWORKS.Syslab 的 Julia、TyPlot、TyMath 生成，没有使用 MATLAB。中文标题使用宋体，坐标、单位和数值使用 Times New Roman。设置、运行信息滚动及界面字号自适应沿用原版本。
